# rift logo

| File | For |
|---|---|
| `rift-logo.svg`, `rift-logo.png` | light backgrounds |
| `rift-logo-dark.svg`, `rift-logo-dark.png` | dark backgrounds |
| `rift-mark.svg`, `rift-mark-dark.svg` | the mark alone, where the name is already written |
| `rift-icon.svg`, `rift-icon.png` | the mark on a navy square: avatars, app icons, the Helm chart |
| `social-preview.png` | the repository's preview image when its link is shared, 1280×640 |

Colors: navy `#0B1F3A` and teal `#14B8A6`; on dark backgrounds the navy becomes white. The name is
set in DM Sans Bold (SIL Open Font License 1.1) and converted to outlines, so the SVGs need no font.
